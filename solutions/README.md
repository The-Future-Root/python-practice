# Solutions

A working solution for every problem. There's almost always more than one good answer, so if yours passes the tests and you understand it, it's a good answer too. Comparing the two is a great way to pick up new tricks.

To run a solution against the tests, copy it into the problem's folder as `exercise.py` (keep a copy of yours first).
